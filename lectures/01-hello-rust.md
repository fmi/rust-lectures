# Инсталация и компилиране

Официално препоръчвания начин да инсталирате Rust е през Rustup: <https://rustup.rs/>.
Rustup е инструмент за инсталиране и поддържане на различни версии на компилатора и на други инструменти и компоненти.

`rustc` - компилаторът на Rust. Oбикновено не се използва директно.

`cargo` - pacakge manager, task runner. Основният инструмент за работа с проекти на Rust. Основни команди:

```sh
# Създава нова директория hello/
# с базовата структура на проект
cargo new hello

# Компилира проекта.
# Компилираната програма се намира в target/debug/<име_на_проекта>
cargo build

# Компилира проекта и изпълнява вашата програма
cargo run

# Същото като build/run, но компилира проекта с оптимизации
cargo build --release
cargo run --release
```

# Синтаксис

## Променливи

Променливи се делкарират с `let`.

```rust
let name = value;
let name: Type = value;
```

Типа на променливата може да се пропусне. В такъв случай той се отгатва от заобикалящия контекст чрез алгоритъм за type inference. Взима се в предвид цялото тяло на фунцкията, а не само предходните твърдения.

```rust
let x = 5;  // типа на `x` е `i32`, защото се подава на функция, която приема като аргумент `i32`
func_with_arg_i32(x);
```

Променливите са immutable по подразбиране, което не позволява модифициране на стойността.
Mutable променлива може да се декларира с `let mut`.

```rust
let mut name = value;
let mut name: Type = value;
```

## Control flow

### if клаузи

Няма скоби около условието. Скобите за блок `{ }` са задължителни.

```rust
if bool_expression {
    // ...
} else if another_bool_expression {
    // ...
} else {
    // ...
}

if 2 > 1 {
    println!("okay");
} else {
    println!("wait what");
}
```

### match

Ще му обърнем внимание в бъдеща лекция.

```rust
match text {
    "foo" => println!("it's foo"),
    "bar" => println!("it's bar"),
    _ => println!("it's something else"),
}
```

### Цикли

`for` цикъла работи с итератори, за които ще говорим в бъдеща лекция.
`while` се изпълнява, докато булевото условие е изпълнено.
`loop` е безкраен цикъл - подобно на `while true`.

Отново няма кръгли скоби след `for`/`while` и скобите за блок `{ }` са задължителни.
Няма еквивален на C-like триелементов `for` цикъл, или на `do-while`.


```rust
for var in iterable {
    // ...
}

for n in [1, 2, 3] {
    println!("N: {}", n);
}

while bool_expression {
    // ...
}

loop {
    // ...
}
```

В тялото на цикъл могат да се използват `break` и `continue`.
Може да се добавят етикети на циклите и съответните етикети могат да се подадат на `break` и `continue`.

```rust
'outer: for x in [1, 2, 3] {
    'inner: for y in [4, 5, 6] {
        if some_condition(x, y) {
            break 'outer;
        }
    }
}
```

## Блокове код

Блоковете код се създават с `{ }` и отварят нов lexical scope.
На блоковете също могат да се закачат етикети и в блок може да се използва `break`, за по-ранно излизане от блока.

```rust
let x = 10;

'blk: {
    let x = 20;
    println!("{}", x); // 20
    break 'blk;
}

println!("{}", x);     // 10
```

## Изрази и твърдения

Много от конструкциите на езика са изрази.

Блоковете са израз - стойността им е стойността на последния израз в блока

```rust
fn main() {
    let x = {
        let a = 1;
        let b = 2;
        a + b
    };

    println!("x = {}", x); // 3
}
```

if-else конструкцията е израз.
По тази причина в езика няма тернарен оператор (`cond ? a : b`).

```rust
let bigger = if a > b {
    a
} else {
    b
};

let bigger = if a > b { a } else { b };
```

match е израз.

```rust
let index = match field {
    "foo" => 0,
    "bar" => 1,
    "baz" => 2,
    _ => -1,
};
```

`loop` е израз - стойността му е каквата стойност е подадена на `break`.
`for` и `while` не са изрази, защото при тях е възможно да се излезе и без `break`.

```rust
let x = loop {
    break 5;
};
```

# Основни типове

## Числени типове

```
i8 i16 i32 i64 i128 isize
u8 u16 u32 u64 u128 usize
f32 f64
```

- `iN` - цяло (signed) число с размер N бита
- `uN` - неотрицателно (unsigned) число с размер N бита
- `isize` и `usize` имат размер колкото машинната дума - 32 бита на 32 битов ОС и 64 бита на 64 битов ОС
- `f32`, `f64` - числа с плаваща запетая

Числовите литерали могат да съдържат долни черти `_` на произволни места, с цел визуално групиране на цифрите и по-добра четимост: `1_000_000`.
Литерал от специфичен тип се декларира, като се добави типа като суфикс на числото: `42u32`. Типа може да се отдели с долна черта, за по-добра четимост: `42_u32`.
Числа в бройни системи различни от десетичната се дефинират с префиксите `0x`, `0o`, `0b`

```rust
let x = 42_u32;
let y = 133_587;
let z = 3.14;
let w = 1.3_f64;

let hex = 0xdead_beef;
let octal = 0o77;
let binary = 0b1010011010;
```

## Булеви стойности

Тип `bool`, стойности `true` и `false`

```rust
let t: bool = true;
let f: bool = false;
```

## Unit

Типа се означава като `()` и има една единствена стойснот: `()`.
Не носи информация, има големина 0 байта (т.е. изчезва в компилираната програма).
Използва се при липса на информация, например за функции, които не връщат резултат.

```rust
let unit: () = ();
```

## Низове

За низове се използват осовно два типа:

* `String` - динамичен низ
* `&str` - резен от низ

Низовете представляват utf8 закодиран текст. Нямат терминираща нула.

### String

Типа `String` представява динамично алокиран низ. Може да се променя и автоматично се реалокира при оразмеряване.
Използва се когато искаме да запазим дадена стойност в променлива или структура.

```rust
// конструиране на низ
// следните изрази са напълно еквивалентни
let s = String::from("Здравей, Rust");
let s = "Здравей, Rust".to_string();

// динамично построяване на низ
let mut s = String::new();
s.push_str("Здравей, ");
s.push_str("Rust");
println!("{}", s);
```

### &str

Типа `&str` се нарича резен от низ (string slice).
Представлява изглед (view) към низ или към част от низ.
Immutable е - през него не може да се променя стойността на низа.

Типа на низовите литерали е `&str`.

```rust
let s = "Здравей, Rust"; // тип &str
```

`&str` е специален вид референция и сочи към памет, която е заделена от някой друг.
Обикновено `&str` или е литерал, или сочи към (част от) `String`.

```rust
let s: = "Здравей, Rust";
let hello = &s[0..14];   // индексирането е по байтове, не по символи
let rest = &s[14..];

println!("{:?}", hello); // "Здравей"
println!("{:?}", rest);  // ", Rust"
```

# Функции

Задаването на типове на параметрите и резултата е задължително.
Върнатата стойност е стойността на последния израз в тялото на функцията.

```rust
fn add(a: u32, b: u32) -> u32 {
    // note no semicolon
    a + b
}
```

Ако фунцкията не връща резултат, типа на резултата е unit.
В този случай не е нужно да пишем `-> ()`.

```rust
fn print_a(a: u32) {
    println!("{}", a);
}

fn print_b(b: u32) -> () {
    println!("{}", b);
}
```

Ако искаме да излезем от функцията преди последния ред, може да използваме `return`.
Използване на `return` на последния ред от тялото се счита за лоша практика.

```rust
fn good_a(a: u32, a_is_bad: bool) -> u32 {
    if a_is_bad {
        return 0;
    }

    a
}
```

## Анонимни функции (closures)

Анонимните

```rust
fn main() {
    let add = |a, b| { a + b };

    println!("1 + 2 = {}", add(1, 2));
}
```

Анономните функции могат да прихващат променливи от заобикалящия ги lexical scope.

```rust
fn main() {
    let x = 5;
    let add_x = |a| { a + x };

    println!("{}", add_x(10)); // 15
}
```

## Macros

Cлужат за генериране на код.
Pазличават се от функциите по `!` след името.

* `println!`
* `format!`
* `dbg!`

# println! macro

```rust
let x = 5;
let y = "десет";
println!("x = {} and y = {}", x, y);
```

`println!` се използва за принтиране на конзолата.

```
println!(format_string, arg1, arg2, arg3, ...)
```

Първият аргумент трябва да е низ литерал и се валидира по време на компилация.
Може да съдържа placeholders:

* `{}` - "display" формат - извежда стойността в human-friendly формат. Само определени типове го поддържат
* `{:?}` - "debug" формат - извежда стойността във формат, наподобяващ синтаксиса на Rust
* поддържат се и специални формати, като:
    * `{:x}` - извежда стойността в шестнайсетична бройна система
    * `{:0.2}` - форматира дробно число с определен брой значи след десетичната запетая
    *  и други - вижте модула [`std::fmt`](https://doc.rust-lang.org/stable/std/fmt/index.html)

```rust
# fn main() {
let x = 255;
let y = "десет";

println!("x = {} and y = {}", x, y);
// x = 255 and y = десет

println!("x = {:?} and y = {:?}", x, y);
// x = 255 and y = "десет"
```

### Принтиране на структури

Типове дефинирани от потребителя не могат да се принтират по подразбиране.
За да се позволи това, може да се използва анотацията `#[derive(Debug)]` при дефиниране на типа.
Това е специален вид макрос, който генерира имплементация на "debug" формата за принтиране.

```rust
#[derive(Debug)]
struct User {
    name: String,
    email: String,
    sign_in_count: u32,
}
```

```rust
println!("{:?}", user1);
// User { name: "Иван", email: "mail@example.com", sign_in_count: 0 }
```
