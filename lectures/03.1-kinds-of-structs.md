# Видове структури

В езика има няколко начина за дефиниране на структура.

## Struct

```rust
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
}
```

## Tuple struct

Структура наподобаваща кортеж (tuple). Може да се възприема като структура с анонимни полета, или като именуван кортеж.

```rust
struct Color(f32, f32, f32);
struct Point(f32, f32, f32);

let black = Color(0.0, 0.0, 0.0);
let origin = Point(0.0, 0.0, 0.0);

println!("r: {}, g: {}, b: {}", black.0, black.1, black.2);
```

## Unit struct

Празна структура. Също като типа unit `()`, има размер 0 байта.

```rust
// Три различни синтаксиса за дефиниране на типа.
struct UnitStruct1 {}
struct UnitStruct2();
struct UnitStruct3;

// Създаване на инстанция.
// Трябва да се използват същите скоби, както при дефиниране на типа.
let u1 = UnitStruct1 {};
let u2 = UnitStruct2();
let u3 = UnitStruct3;
```

# Mетоди

В Rust, полетата и логиката на типа се дефинират отделно.

Методи и асоциирани функции се дефинират извън дефиницията на структурата, в отделен impl-блок. Методи наричаме функции, които приемат като първи аргумент `self`, `&self` или `&mut self` (method receiver). Функции, които не приемат `self` под някаква форма наричаме асоциирани функции.

```rust
struct User {
    username: String,
    email: String,
    sign_in_count: u64,
}

impl User {
    fn new(username: &str, email: &str) -> User {
        User {
            username: username.to_string(),
            email: email.to_string(),
            sign_in_count: 0,
        }
    }

    fn sign_in(&mut self, email: &str) -> bool {
        if self.email == email {
            self.sign_in_count += 1;
            true
        } else {
            false
        }
    }
}
```

Чрез impl-блок дефинираме фунцкии в полето от имена (namespace-a) на даден тип. Можем да достъпваме чрез оператор `::` - `User::new`, `User::sign_in`.

Освен чрез `::`, методите могат да се извикват и директно върху инстанция на типа.

```rust
// Извикване на асоциирана функция.
let mut user = User::new("Аз", "mail@example.com");

// Извикване на метод.
// Еквивалентно на `User::sign_in(&mut user, "mail@example.com")`
user.sign_in("mail@example.com");
```

## Типа `Self`

Вътре в impl-блок имаме достъп до типа `Self`, който е псевдоним на типа, за който сме отворили impl-блока.

Различните видове method receivers имат следното значение:

* `self` е еквив. на `self: Self` - приема инстанцията по стойност, т.е. премества инстанцията в тялото на метода
* `&self` е екивив. на `self: &Self` - приема споделена референция към инстанцията
* `&mut self` е еквив. на `self: &mut Self` - приема mutable референция към инстанцията

```rust
struct Rectangle { width: f64, height: f64 }

impl Rectange {
    fn new(width: f64, height: f64) -> Self {
        Self { width, height }
    }

    fn area(&self) -> f64 {
        self.width * self.height
    }
}

// е еквивалентно на

impl Rectangle {
    fn new(width: f64, height: f64) -> Rectange {
        Rectange { width, height }
    }

    fn area(self: &Rectange) -> f64 {
        self.width * self.height
    }
}
```

## Конструктури и деструктури

В езика няма конструктури на типове.

За целта се използва асоциирана функция, която връща `Self`, т.е. създава инстанция от типа. По конвенция функцията се казва `new` или `from_*`, но може да има друго име, ако това е логично за типа - например `File::open`.

## Overloading

Rust не поддържа function overloading, т.е. съществуването на няколко функции с еднакво име, но различни параметри.
